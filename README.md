## 📌 About This Repository

This repository showcases practical data analytics projects developed by **Shruti Saxena**.

Each project follows a typical data analysis workflow:

**Data Collection → Data Cleaning → Exploratory Data Analysis → Visualization → Analysis → Insights**

The projects demonstrate the use of Python, Jupyter Notebook, data analysis libraries, visualization techniques, statistical analysis, and machine learning concepts.

The goal of this repository is to build practical experience with real-world datasets and demonstrate the ability to transform raw data into meaningful insights.

- COVID-19 case trends

- Geographic visualization
- Socioeconomic analysis
